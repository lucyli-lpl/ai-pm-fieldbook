## 通过率怎么定（PM 的产品决策）

- **视角转换**：通过率不是「我要多好」，而是「我能容忍多坏」——定的是可容忍的失败率。
- **按失败代价定，不按题目难度定**：先给测试按**严重度 S0–S2** 分级，再按级配通过率。
  - S0 硬伤（越权、编造、越界判断）→ **100% 零容忍，做成发布门禁**，不参与平均，一条 fail 即阻断上线。
  - S1 功能失败（路由错、推错资源）→ 高（如 95%+），核心区尤甚。
  - S2 体验缺陷（该追问没追问、啰嗦）→ 中（如 80–90%），可迭代。
  - 「优秀」为加分观察项，不进验收硬线（挪监控观察）。
- **冷启动无基线时**：先定「方向 + 相对关系」（谁必须比谁高），跑一轮拿真实基线，再把目标设成「基线之上的改进」，不空定长期达不到的理想值。
- **行动后果反检验**：每条线都要能回答「掉到线下我会做什么」（阻断发布 / 触发迭代 / 仅观察）；答不出行动的线是假指标。
- 通过率是给「一批题」的统计量，因此**场景集合的代表性**直接决定它是否有意义。

## PM 在评测中的职责边界

Hamel 的方法预设「看数据 / 搭工具 / 提要求」是一个人的事；在 PM / QA / Dev 分工的组织里，需要把它翻译成协作。核心原则：**PM 定义「目标状态」，QA 定义「如何验证达到目标状态」。**

**职责分界尺：**

| 维度 | 谁定 |
|---|---|
| 测什么场景（覆盖哪些，尤其 S0、易混负样本、关键边界） | **PM** |
| 每个场景的期望行为（该做什么动作、达到什么结果） | **PM** |
| 多好才算过（通过标准、通过率、S0 零容忍） | **PM** |
| 关注哪些指标及其方向/优先级 | **PM** |
| 用什么题触发场景（具体出题、造多少、怎么造） | QA |
| 怎么判定一道题过没过（断言代码、评分表实现） | QA / Dev |
| 怎么跑、多久跑、用什么工具 | QA / Dev |

**PM 该产出的颗粒度**：到「场景类别 + 每类期望行为 + 通过标准（含 L1/L2 归属与通过率/零容忍）+ 关注指标及方向」为止。**规定「场景类别」而非穷举每道题**；具体出题、断言实现、评分表、跑测编排交给 QA。

**指标该规定到哪（含两个坑）：**
- **分类型任务**（意图路由、资源匹配）→ 用**精度 + 召回**（分意图统计）；既怕漏又怕误时用 F1。PM 定「关注哪些 + 哪个优先」，**数值靠跑出基线后校准，不预先虚构**。
- **坑一：指标误用**——生成质量、追问质量、降级诚实度**没有唯一对错，不能套准确率/F1**，应走 L2 人工评通过率 / 人机一致率。在主观质量上硬套分类指标是错误。
- **坑二：类别不均衡**——真实流量里某意图可能占多数、badcase 极少，**别看单一总准确率**（全猜大类也能虚高），要**分意图 / 分场景类别统计**。

**看数据的分工**：PM 与 QA 看同一批数据，但目的不同——QA 为**执行**（过没过、覆盖够不够），PM 为**定义**（什么算好、哪些失败最该管、边界在哪）。PM 要争取的是**看原始 trace 的入口**，产出评分 rubric、S0 清单、badcase 分类与归因规范，供 QA 执行时使用。

**工具的处理**：看数据 / 打标工具不是 PM 亲手搭的杂活，而是 PM 写的**一份内部工具需求**——先轻量证明价值，再换资源。

## 决策层心法：定严重度与通过率（PM 不可外包）

决策层的两件套：**严重度是因（按后果轻重给场景分级），通过率是果（按严重度给每级定达标线）**。两者背后是同一样东西——产品价值观：什么绝不能破（安全）、什么应该做到（准确）、什么最好做好（体验）。

**定严重度的心法：**

- **锚点**：严重度衡量的是「后果对用户/业务的伤害有多深、可不可逆」，**不是错误的大小，更不是团队修复的麻烦**。
- **三把尺，任一指向严重就一票抬级（取最坏不取平均）**：
  1. **可逆性**：错了还能不能救回来？不可逆 → 抬向 S0。
  2. **外部性**：伤害只停在对话里，还是溢出到真实世界？溢出 → S0。
  3. **违背哪种承诺**：安全 > 准确 > 体验。破坏边界/安全 → S0；破坏结果/准确 → S1；破坏处理/体验 → S2。
- **S0 要少而硬、能穷举**：S0 是发布门禁，权威来自稀少。判据狠问题：「这条挂了还坚持上线，出事我能不能承担？」承担不起→S0。
- **写判据而非只给标签**：不写「越权=S0」，写「越权=S0，因不可逆+有外部性+破坏安全承诺」。
- **拿不准先归中间级**：不确定是不是 S0 → 先放 S1 挂观察。
